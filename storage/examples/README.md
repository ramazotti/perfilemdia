# Exemplos locais (story)

Prévias JPEG geradas para revisar texto na foto do story (1080×1920, legenda de 270 caracteres).

Regenerar:

```bash
php bin/render_story_examples.php
```

Cada execução cria uma pasta `story-270-AAAA-MM-DD_HHMMSS` com combinações de estilo, posição e cor.

A pasta `story-270-2026-09-27_094746` ficou versionada como referência (opacidade 90% em caixa e balão).
